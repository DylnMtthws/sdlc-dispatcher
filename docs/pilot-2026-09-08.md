## Recovered partner-zone patch

The CSS forced the zone to remain 170 px wide using `!important`. The patch removes
that override and calculates width from commander count. It preserves 170 px for
one commander and expands to 293 px for a pair. Only these files changed:

- `src/sabermetrics/ui/static/deck-lab-builder.js`
- `src/sabermetrics/ui/static/deck-lab.css`
- `tests/test_playmat_commander_zone.py`

The recovered review diff is 19,901 bytes. Completed edit records included full
before/after contents; the existing frontend files' recorded before contents
matched the committed source. The recovered files were treated as untrusted and
verified in fresh offline containers. This is controller recovery from logs,
not proof that the original attempt completed the automatic pipeline.

Independent evidence:

- Original source plus the new test: **1 failed, 1,331 passed, 31 skipped**; the
  failing test is the new commander-zone test.
- Recovered patch: ruff, Black, mypy (134 source files), and **1,332 tests passed,
  31 skipped**.
- Chromium at 1440 × 900: one commander stays 170 px wide; two expand to 293 px;
  every commander card fits inside its zone. No page JavaScript errors.
- Browser checks substituted the exact verified JS/CSS into the localhost
  synthetic preview using request interception. The backend remained baseline;
  all external requests were blocked. This was not a deployed candidate image.

The generated regression test inspects CSS and evaluates the width expression;
that is weaker than a persistent browser regression. The independent browser
check covers the actual rendered dimensions, but should be made a repeatable
project gate before unattended UI repairs are enabled. Synthetic cards have no
loaded artwork, and existing overlap between separate zones is outside this fix.

## Dispatcher corrections

1. Cursor discovery uses `api2.cursor.sh`, while coding traffic uses API5 agent
   hosts. The restricted proxy now permits the eight exact documented API/agent
   hosts. No wildcards or general outbound access were added. A credential-free
   probe verified CONNECT, TLS certificate validation, and HTTP/2 negotiation to
   the observed agent endpoint. Source: [Cursor network documentation](https://prod.cursor.com/docs/enterprise/network-configuration).
2. `max_patch_bytes` now measures the UTF-8 unified review diff, including context,
   rather than adding complete before/after files. Complete source snapshots still
   have their own size limit. Tests cover small repairs in large files, oversized
   rewrites, and multibyte output.
3. The prompt now explicitly requires a new test that fails against the original
   source, matching the existing verification gate.

All **60 dispatcher tests passed**, including five actual Docker isolation tests;
ruff and Black pass. The pilot produced useful code but needed controller repairs
and manual recovery. Keep explicit review before publication or deployment.
